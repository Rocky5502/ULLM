# IASEAI'27 Submission Readiness Checklist

Last checked: 2026-09-03.

## Official 2027 information currently public

Source of truth: `https://www.iaseai.org/our-programs/iaseai27`

- Main conference: **9–10 February 2027**, UNESCO House, Paris; workshop days follow on 11–12 February.
- Paper/proposal portal opens: **18 September 2026**.
- Paper proposal submissions close: **2 October 2026**.
- Reviews shared: **2 November 2026**.
- Optional paper author responses due: **4 November 2026**.
- Decisions: **6 November 2026**.
- The public page describes papers as original work relevant to safe and ethical AI, submitted for peer review with optional archiving.
- All authors should have an **OpenReview account before 18 September** because account verification can take time.
- Strong theme fit for this project: **Evaluations & risk quantification** and **Control, oversight, & verification**; secondary fit includes robustness/safety-critical AI depending on final framing.

## Formatting status — do not overclaim

As of this check, the IASEAI'27 public page does **not** expose a detailed 2027 paper template/page-limit guide. The current `paper/` directory therefore uses the AAAI-2027 style only as a **provisional working layout**. Do not state that this is the official IASEAI'27 format.

The IASEAI'26 guide allowed up to 10 pages of main text excluding references and required its own template, but that is **historical precedent only**, not a 2027 rule. Re-check the 2027 portal immediately when it opens and migrate the source if the official template differs.

Historical reference: `https://www.iaseai.org/IASEAI%20%2726%20Paper%20Submission%20Guide.pdf`

## Before the paid experiment

- [ ] GitHub CI is green on Python 3.10/3.11/3.12.
- [ ] Zero-API synthetic end-to-end pipeline passes.
- [ ] Paper build workflow is green.
- [ ] `python scripts/fetch_imperfective_nli.py` has produced the exact local dataset and `data/MANIFEST.local.json`.
- [ ] `python scripts/preflight.py` passes locally.
- [ ] `configs/experiment.yaml`, `configs/models.yaml`, prompts, and preregistered hypotheses are committed and unchanged.
- [ ] All five authors/model-endpoint assumptions in the manuscript agree with the config.
- [ ] `ZZZ_API_KEY` is present only in the local environment.
- [ ] `python scripts/check_models.py` confirms every configured gateway ID immediately before execution.
- [ ] The live model-catalog snapshot is retained under `results/catalog/`.

## Paid-run authorization gates

- [ ] Run `scripts/run_frozen.ps1` (Windows) or `scripts/run_frozen.sh` (POSIX).
- [ ] Review preflight + live catalogue before typing **SMOKE**.
- [ ] Type **SMOKE** only when ready to authorize the 100-call paid smoke test.
- [ ] Review the smoke audit and summary.
- [ ] Type **RUN** only when ready to authorize the remaining 15,800 main-study calls before retries.
- [ ] Do not bypass a failed manifest-aware audit.

## After the frozen run

- [ ] Every run family has `status: PASS` in its audit JSON.
- [ ] Requested/returned model IDs and run dates are reported accurately.
- [ ] 10,000-replicate verb-cluster bootstrap artifacts exist.
- [ ] RQ1/RQ2/RQ3 processed CSVs exist and pass spot checks.
- [ ] Result figures are generated from processed artifacts as PDF + SVG.
- [ ] `paper/generated/*.tex` is regenerated by code; no numerical cell is hand-edited.
- [ ] The abstract, Results, Discussion/Limitations, and Conclusion are rewritten from real audited results rather than TBD prose.
- [ ] Any negative/null result is reported rather than hidden through model, prompt, or threshold selection.
- [ ] Exact API call/token cost is reported where the gateway supplies usage metadata.

## Submission-week checks

- [ ] Re-check the official IASEAI'27 portal/template and migrate from provisional AAAI style if required.
- [ ] Verify anonymity/double-blind rules from the **2027** guide; do not assume 2026 wording is unchanged.
- [ ] Verify archival/non-archival options and originality/dual-submission rules from the 2027 guide.
- [ ] Check author accounts, conflicts, keywords, subject areas, abstract, and supplementary-material policy in OpenReview.
- [ ] Ensure the Statement of Contributions satisfies the 2027 wording.
- [ ] Run a final reference audit: every citation exists, metadata is correct, and no uncited bibliography entries remain.
- [ ] Run final PDF checks for page count, fonts, figure readability, broken links, anonymity, overfull boxes, and accessibility.
- [ ] Confirm all result claims are traceable to released/frozen artifacts.

## Scientific red lines

1. No fabricated or estimated result may enter the paper.
2. No poorly performing model may be removed from the primary panel because of its result.
3. No robustness prompt may replace the neutral primary condition because it performs better.
4. No selective threshold may be chosen on the final test results and then presented as predeclared.
5. High entropy must not be described as successful semantic uncertainty recognition; the Group-C target is calibrated probability on `Unknown`.
6. Lower TBR on ImperfectiveNLI must not be described as proof of end-to-end deployment safety.
7. Gateway aliases must not be presented as immutable vendor-direct checkpoints.
