# ULLM Artifact Guide

This repository is the public research artifact for the IASEAI'27 submission.

## Included

- experiment configurations
- reproducibility scripts
- validation and auditing utilities
- analysis tooling
- documentation

## Excluded

The repository intentionally excludes:

- API keys
- private credentials
- raw private model responses
- local execution files

## Reproduction philosophy

The artifact separates protocol verification from model execution. Researchers can inspect the complete evaluation workflow without requiring access to private execution environments.
